# 検証記録

環境: Xcode 15.2 / iOS 17.2 Simulator。最低対応OSはiOS 17.0。

## 確認済み

- シミュレータ向けアプリ・テストのビルド。
- 実機向けarm64ビルド（署名なし）: `BUILD SUCCEEDED`。
- iPhone SEでロジックテスト6件、UIテスト2件、計8件成功（失敗0）。
- 画面操作で岩を4回たたく → ブラシで砂を払う → 骨を拡大 → 汚れをすべて磨く → 収集、を8部位分実行。
- 8部位の完成画面、骨格の組み立て表示、再プレイで0/8へ戻ることを確認。
- 発掘画面の道具・収集ボタンがiPhone SEで操作可能。収集画面も表示確認。
- 途中のみがき保存・復元、誤った道具の無効化、二重収集防止、不正セーブからの復帰、リサイズ時の状態維持を単体テストで確認。
- 初回実装時にはiPhone 15でもロジックテスト6件成功と、拡大みがきの表示・操作を確認。
- `index.html` の差分なし。GitHubの `main` は `c14618e764d733e1c51bbe575165898c0029e4e2` のまま。

小画面の目視確認で骨にかぶる飾りラベルを見つけたため、発掘面・みがき面から除去しました。最終版はこの表示だけを追加修正しています。ラベル除去後も実機向けビルドは成功しました。

## 実行時の環境制約

再開後のiPhone 15シミュレータが起動を完了せず、iPhone SEへ切り替えました。iPhone SEも初回起動・自動操作開始に時間を要しましたが、その後は8部位の通しテストに成功しました。この起動不調をゲームのテスト失敗として数えていません。

ラベル除去後の追加UIテストは、テスト実行前の起動準備中にランナーがsignal killで終了しました（`Early unexpected exit ... before starting test execution`）。したがって、この追加テストは未確認です。上記8件の成功はラベル除去前の実行結果であり、最後の表示変更後の成功とは区別しています。

実機への署名・インストール・触覚の体感確認は、利用者のTeam設定と接続したiPhoneが必要です。今回確認した実機向け成果は署名なしのコンパイルです。
